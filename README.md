Python project to automatically send emails using Gmail SMTP server.

Features:
- Python send emails automatically.
- Uses Gmail SMTP to send emails.
- Permits setting the recipient, subject and message.
- Uses Google App Password for authentication.

Technologies Used:
- Python
- SMTP (smtplib)
- Gmail

How It Works:
The program connects to Gmail’s SMTP server, authenticates using a Google App Password, and then sends an email to the recipient you specify.

Set up:
1. Install Python.
2. Generate an App Password in Google.
3. Add your email credentials to the program.
4. Run the python script

Security: Do not post your real Google App Password or other private credentials.

What I found out:

This project provided me an opportunity to practise Python, work with SMTP/email services, handle user input, and connect a Python program to an external service.
